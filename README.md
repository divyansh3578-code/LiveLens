# LiveLens AI 🌐

An AI-powered assistant that connects LLMs
with live APIs to deliver real-time information.

## Features
- Gemini AI integration
- Live weather information
- News search
- Tool calling and execution
- Express.js backend
- Environment-based configuration

## Tech Stack
- Node.js
- Express.js
- Google Gemini API
- REST APIs
- MongoDB (if configured)

## Installation

1. Clone the repository
2. Install dependencies

npm install

3. Create a .env file
4. Add your Gemini API key
5. Start the server

npm run dev

## Environment Variables
GEMINI_API_KEY=
GEMINI_MODEL=
PORT=
